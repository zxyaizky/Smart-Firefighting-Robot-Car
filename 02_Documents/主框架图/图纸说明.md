# 系统主框架图

已通过本机 Visio 生成原生可编辑 `.vsdx`，另附 PNG 预览和 SVG 矢量图。框、文字及箭头均为 Visio 对象。

依据 2026-10-31 磁盘上的项目清单和顶层源码整理，未修改 RTL、固件或工程配置。

## 采用的工程

- A：`../lab_ex3_osd_SC500_720/lab_ex3_osd/td_project/camera_to_dsi_display.al`，其入口为 `user_source/hdl_source/design_top_wrapper.v`。
- B：`../test/b_vexriscv_main_20261013/work_B/td_project/camera_to_dsi_display_lidar.al`，其入口为 `firmware/linux_wifi/lidar_hdmi/rtl/design_top_wrapper.v`。本图使用这版救援联动工程，不采用较早的 wifi_flash 顶层。

## 与代码的对应

| 图中功能 | 当前代码入口 / 实例 |
|---|---|
| A 摄像头、ISP、DDR、HDMI | A 顶层 `u_isp_top`、`video_in`、`video_out`、`u_hdmi_tx` 等 |
| A 人员推理、参数供给 | A 顶层 `u_npu_video_input`、`u_npu`、`u_npu_ddr`、`u_npu_u33_mcu_bridge` |
| A 视频与人员框发送 | A 顶层 `u_udp_video_input`、`udp_video_metadata`、以太网发送连接 |
| B 本地视频与网络视频切换 | B 顶层 `network_display_select_reg`，B4 消抖后在帧边界选择 |
| B 黄绿识别 | B 顶层 `u_rescue_color`，模块 `color_green_yellow_frame` |
| 人员 / 黄绿 / 距离汇合 | B 顶层 `u_rescue_sensors`，模块 `rescue_sensor_mailbox` |
| 自动任务与运动控制 | B 顶层 `u_rescue_control`、`u_car_uart_tx` |
| 六关节机械臂 | B 顶层 `u_arm_auto`、`u_arm_buttons`、`u_arm_pwm` |
| 消防瞄准与喷水 | B 顶层 `fire_servo_position_inst`、`fire_position_pump_inst`、`u_fire_spray_burst` |
| 心率 / 血氧 | B 顶层 `u_max30102_top`、`u_max30102_osd_cdc` |
| 语音 | B 顶层 `u_rescue_voice`；A 另有独立 `u_voice_uart_tx` |
| Linux 与地图 | B 顶层 `u_vexriscv_linux`、`u_lidar_map`，MMIO 位于 `0xF0020000` |
| 雷达转发 | `firmware/linux_wifi/lidar_hdmi/send_map.py`，调用 `lidar_ssh/send_live.py`，经电脑 Wi-Fi、ESP32 和 UART/PPP 进入 Linux |

图中按主功能合并了 CSI/ISP、DDR、显示算法和 OSD 的内部子模块。绿色抓取、人员停车和黄色消防由 FPGA 状态机决定；Linux 点云链路用于地图生成和近似着色。血氧用于显示，普通超声波避障和旧双目测距不作为当前主功能绘入。

已核对正式工程入口、关键实例和 VSDX 文件结构，并检查导出图片的文字及连线布局。`来源核对.json` 保存实际读取的源码路径和 SHA256。此图描述源码结构，不代表当前 bitstream 已部署或功能已完成实板验收。
