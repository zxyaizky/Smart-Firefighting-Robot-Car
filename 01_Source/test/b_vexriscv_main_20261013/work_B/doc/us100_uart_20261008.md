# US-100 UART 与双目距离同时显示

2026-10-08。按用户选择，US-100 保留背面跳线帽，使用串口 UART 模式。功能接入 B 测距板，A/NPU 板不变。两项距离只做独立显示对比，不融合，也不改变现有舵机和喷水控制。

## 接线

以下 J1 指 B 板的 40 针扩展接口，按接口针脚编号连接，不按 FPGA 封装名找排针。

| US-100 端子 | B 板 J1 | FPGA/电源 | 方向 |
|---|---|---|---|
| VCC | 第 29 脚 | VCC_3V3 | 给 US-100 使用 3.3 V 电源 |
| GND（两个 GND 至少连接一个） | 第 30 脚或第 12 脚 | GND | 与 B 板共地 |
| Trig/TX | 第 6 脚 | GPIOA_5 / T3，`us100_uart_tx_out` | FPGA 发送命令，传感器接收 |
| Echo/RX | 第 7 脚 | GPIOA_6 / T2，`us100_uart_rx_in` | 传感器返回数据，FPGA 接收 |

US-100 的 Trig/TX、Echo/RX 标注按主机侧功能命名，实际接法是 FPGA TX 接 Trig/TX，FPGA RX 接 Echo/RX。不要仅根据一般 UART 的交叉接法反接这两个标注。[官方接线说明](https://learn.adafruit.com/ultrasonic-sonar-distance-sensors/python-circuitpython)

US-100 可以使用 3.3 V 电源，本工程选择 3.3 V，以匹配 FPGA 的 LVCMOS33 输入。不要把舵机已有的外部 5 V 线直接作为本接线表的超声波供电线。舵机仍使用其原 5 V 接线，信号 J1 第 4 脚不变；水泵 MOS 信号仍为 J1 第 5 脚，外部电源回路不变。[US-100 电源和逻辑说明](https://www.adafruit.com/product/4019)

已视觉核对开发板原理图 `HX1P35B_FT_40P_6.pdf` 的 J1 针脚及 `HX1P35B_FT_40P_3.pdf` 的 FPGA BANK21：GPIOA5=T3、GPIOA6=T2、BANK21 VCCIO=3.3 V。修改前两引脚未被现有约束占用，新增约束没有重复管脚。原 J1 第 1/2/3 脚的小车 RX、双目同步、小车 TX 保留。

## HDMI 显示

保留原绿色框及其随框移动的 D/Z 标签。另在左下角增加固定两行，起点 X=16、Y=648，宽 240 像素；第二行 Y=672，避免现有四角指示区域：

```
STEREO: 00584MM
US100:  00630MM
```

两行以毫米为单位，五位数字包含前导零。双目行是绿色，超声波行是青色。无效时数字位置为 `-----`，不显示虚假的零距离。双目有效与 US-100 有效状态互不影响。数值经过串行 BCD 转换后，在垂直消隐期整组发布，避免同一帧数字混合。底部两个小文字条内使用黑底，条外像素与原视频逐位一致，不增加 RGB、VS 或 DE 时钟延迟。

双目显示使用原 `stereo_hdmi_result_latch` 的 `stereo_display_range_valid`（1 位）和 `stereo_display_distance_mm`（16 位），沿用现有稳定化结果及 45 mm 基线/当前 `FB_CONSTANT=11110`。没有改动双目匹配、测距、投影或绿色框算法。

超声波显示使用新增 `us100_uart_ranging` 输出 `S_us100_distance_mm`（16 位）和 `S_us100_distance_valid`（1 位）。它测量传感器正前方声波的有效反射目标，不根据火焰框挑选测量对象。做精度对比时，应让两个系统对准同一实体目标；它不能直接识别所测的反射物是不是火焰。

## 接口和计数参数

实际接入时钟为 `S_hdmi_pixel_clk`：顶层 `PLL u_PLL.clk4_out`，活动 IP `user_source/ip_source/PLL/.params_PLL.txt` 的 `CLK4_ACTUAL_FREQ_DISP=75.000000` MHz。另一个未用于此连接的 PLL 模板参数不是本模块分频依据。

| 参数 | 值 |
|---|---:|
| `CLK_FREQ_HZ` | 75,000,000 Hz |
| UART | 9600 baud，8N1，空闲高电平 |
| 每串口位周期 | 四舍五入 7,813 个时钟，计数最后值 7,812 |
| 实际波特率 | 约 9,599.39 baud，误差约 -0.0064% |
| 命令 | 单个二进制字节 `0x55`，低位先发送 |
| 回复 | 高字节先、低字节后，`{high, low}` 即毫米距离 |
| 启动等待/轮询间隔 | 200 ms，15,000,000 时钟周期 |
| 命令发送后回复超时 | 100 ms，7,500,000 时钟周期 |
| 有效距离范围 | 20～4,500 mm |

[官方驱动](https://github.com/adafruit/Adafruit_CircuitPython_US100/blob/main/adafruit_us100.py) 也使用 `0x55` 和高字节优先的两字节回复。

命令之间保留上次有效距离，后续事务超时、缺字节、停止位错误或距离越界时撤销有效并显示横线。完整结果每约 200 ms 更新，失败后的显示撤销再等待下一垂直消隐期。超时后的迟到字节在静默阶段被丢弃，下一命令清空接收过程。原始 US-100 两字节协议没有校验和/事务编号；软件无法认证任意噪声构造出的合法字节或跨过下一事务的严重迟到回复。

所有新增测距与显示逻辑都在同一 75 MHz 时钟域；仅传感器异步 RX 用两级同步。没有新建多位距离跨时钟域路径。复位为外部 `I_rst_n` 与现有显示域 `S_hdmi_rst_n` 组合的高有效同步复位，输出也立即门控撤销有效并恢复 TX 空闲高。

## 新增模块接口

- `us100_uart_rx.v`：参数 `CLK_FREQ_HZ`、`BAUD_RATE`；输入 `clk/rst/enable_i/uart_rx_i`；输出 `data_o[7:0]/valid_o/error_o`。半位验证起始位，中位采样八个数据位，验证停止位。
- `us100_uart_ranging.v`：输入 `clk/rst/uart_rx_i`；输出 `uart_tx_o/distance_mm_o[15:0]/distance_valid_o/result_update_o`。发送命令、收两字节及处理超时与范围。
- `dual_distance_overlay.v`：输入像素坐标、RGB、DE、帧开始和两个有效/毫米值；输出组合 `rgb_o[23:0]`。复用原 `osd_char_lib`，32 个时钟依次转换两个 16 位值，不使用运行时除法。

完整 Verilog 代码在 `td_project/import/`。按 Verilog-2005 检查了模块结构、命名端口、明确位宽、同步复位、单一驱动、组合默认值及无锁存器；无 AXI 接口。各独立状态机分别位于独立模块，不修改既有小车 UART。
