# B 板 SW2 拨码开关控制水泵测试

2026-10-07。用户已确认该手动测试可喷水，现默认已恢复 `PUMP_MANUAL_TEST_MODE=0`，SW2 不参与自动控制，详见 `doc/automatic_spray_20261007.md`。本说明记录保留的拨码测试：设为 1 并重新生成/烧录后，可检查 GPIO、MOS 驱动模块和水泵是否能工作。测试模式直接由拨码开关控制水泵，不要求火焰、距离或瞄准有效；舵机仍按原位置控制模式追踪火焰。

## 开关和接线

开发板原理图 `HX1P35B_FT_40P_3.pdf` 和 `HX1P35B_FT_40P_8.pdf` 确认：板上丝印 **SW2** 对应网络 **SW1**，接 FPGA **B4**，BANK42 为 3.3 V。该开关此前未使用。板上 SW1 已控制自动曝光，本次没有占用它。新增顶层输入 `I_pump_test_switch` 已在 `pin.adc` 约束为 B4/LVCMOS33。

水泵输出沿用 `pump_ctrl_out`：FPGA **T4**，扩展接口 **J1 第 5 脚**，高电平启动，低电平关闭。

- B 板 J1 第 5 脚接 MOS 模块的控制输入 IN/SIG，模块须能识别 3.3 V 控制电平。
- MOS 控制地与 B 板 GND 共地；已有可靠共地时可以连接另一块板的 GND。
- 水泵由符合其额定电压的外部电源供电，负载及电源端按 MOS 模块自身端子标识连接。水泵电流经过外部电源和 MOS 的负载回路。
- FPGA GPIO 只接控制输入，不能给水泵直接供电。
- 舵机信号仍接 J1 第 4 脚，接线和控制不变。

## 下板操作

1. 打开 B 板工程 `td_project/camera_to_dsi_display.al`，重新综合、布局布线、生成并烧录新文件。本次没有代为生成或烧录。
2. 当前参数 `PUMP_TEST_SWITCH_ACTIVE_LOW=1`：SW2 输入低电平为开，高电平为关。没有确认拨码上下方向与这个电平的对应关系，不依赖开关的 ON 字样来判断。
3. 上电、重新配置或复位后，必须先让开关在关的位置稳定至少 20 ms，再拨到开的位置稳定至少 20 ms，水泵才会启动。一直留在开的位置复位不会自动启动。
4. 不知道哪一侧是关时，将 SW2 拨到一侧停约 0.1 秒，再拨到另一侧停约 0.1 秒，再拨回来停约 0.1 秒。观察哪一侧启动并记住方向；两次切换可完成一次有效的关→开。
5. 拨回关的位置，输出在两级同步后关闭，不等待完整消抖周期；按住复位也强制关闭。释放复位后仍须重新完成关→开。

手动测试与图像链路无依赖，只需 B 板本身的 50 MHz 晶振时钟与外部复位。独立舵机自检 `SERVO_TEST_MODE=1` 仍优先强制关闭水泵；当前该参数为 0。

## 参数与恢复

参数均在 `user_source/hdl_source/design_top_wrapper.v`：

| 参数 | 当前值 | 用途 |
|---|---:|---|
| `PUMP_MANUAL_TEST_MODE` | 0 | 当前自动喷水；改为 1 重新启用 SW2 手动驱动测试 |
| `PUMP_TEST_SWITCH_ACTIVE_LOW` | 1 | 输入低电平启动；改为 0 反转开关方向 |
| `PUMP_TEST_DEBOUNCE_MS` | 20 | 稳定关状态解锁、稳定开状态启动的消抖时间 |
| `FIRE_PUMP_ACTIVE_HIGH` | 1 | GPIO 高电平启动；低电平有效的 MOS 模块使用 0 |

修改这些综合参数后需要重新生成并烧录。恢复自动模式保留 SW2 输入和约束，手动分支不参与控制。
