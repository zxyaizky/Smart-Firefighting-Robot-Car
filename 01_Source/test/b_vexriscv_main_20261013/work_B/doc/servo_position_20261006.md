# 固定摄像头：舵机按火焰位置转到目标后停止

**2026-10-07 喷水条件更新：** 手动驱动验证成功后，当前已恢复 `PUMP_MANUAL_TEST_MODE=0`。位置模式下舵机到达目标并稳定 200 ms 后，连续确认 3 次独立有效火焰检测即可喷水；用户选择暂不依赖测距，也不再要求固定摄像头中的火焰框回到中心。本文件原喷水许可描述已被 `doc/automatic_spray_20261007.md` 替代。舵机位置控制保持本文件所述行为。

用户已确认暂未装喷嘴，摄像头固定。原控制器每收到一个偏心的新检测，就累计移动 1°；固定摄像头的 X 不会因舵机转动而自行回到中心，因此会不断累计到机械限位。新位置模式将 X 换算为有限的目标角度，逐步转到目标后保持。

## 默认行为

仍在 B 测距板，沿用 A/NPU 板经 Ethernet 送来的真实检测结果。`fire_control_bridge` 原有独立结果身份、160 宽中心坐标、丢失判断、5 秒新鲜度超时全部保留。没有依赖不准确的双目 Z 来计算舵机角度。

- 默认中心 X=80 对应 90°。
- X 在 75～85 内时目标为 90°。
- 中心以外，默认每 4 像素约 1°，偏差四舍五入。左侧减小角度，右侧增大角度；`FIRE_SERVO_REVERSE=1` 可反向。
- 三个独立检测 X 的中值决定目标，第一份新检测直接播种历史，丢失后清除历史。
- 每 100 ms 最多调整 1°，准确停在计算的目标角度，不会越过目标；安全限制仍为 10°～170°。
- 重复相同位置不会累计角度；没有新结果时可完成已接收的有限目标，直到现有桥撤销 fire_valid。相同 UDP 结果仍不能刷新新鲜度。
- 火焰有效信号撤销时立即停止继续步进并保持当前角度；恢复必须有新的独立检测。复位回 90°。

| X | 默认目标角度 |
|---:|---:|
| 0 | 70° |
| 40 | 80° |
| 60 | 85° |
| 75～85 | 90° |
| 100 | 95° |
| 120 | 100° |
| 159 | 110° |

这是初始线性映射，没有声称已完成相机到喷嘴的机械标定。没有喷嘴、舵机编码器或物理反馈时，只能验证 PWM 指令行为；后续需校准中心方向及像素到角度比例。固定摄像头不能以火焰是否移回画面中心来验证舵机是否瞄准。

## 参数与接线

实际 B 顶层 `user_source/hdl_source/design_top_wrapper.v`：

```verilog
parameter FIRE_SERVO_POSITION_MODE = 1'b1,
parameter integer FIRE_SERVO_POSITION_INTERVAL_MS = 100,
parameter integer FIRE_SERVO_PIXELS_PER_DEGREE_SHIFT = 2,
parameter integer FIRE_SERVO_SETTLE_MS = 200,
```

`PIXELS_PER_DEGREE_SHIFT=2` 表示 2²=4 像素/度，改为 1 时角度变化更大，3 时更小。此比例是编译常量移位，没有引入动态乘除法、图像 RAM 或新的时钟域。`FIRE_SERVO_POSITION_MODE=0` 恢复原增量控制，适用于相机随舵机共同转动的安装；本轮没有修改原 `fire_aim_controller.v`。

仍为 75 MHz 实际控制时钟，100 ms 步进周期为 7,500,000 时钟，200 ms 等待为 15,000,000 时钟。50 Hz PWM 实现与 1,500,000 周期计数均未改。

GPIO 仍为 `servo_pwm_out=U1/J1.4`、`pump_ctrl_out=T4/J1.5`；外部 5 V 供 MG90S，红色供电、棕色地、黄色信号。供电地与 B 板共地。引脚约束本轮未修改。

## 水泵许可

原 `fire_aim_controller` 的三份独立中心检测锁定、有效火焰、身份匹配距离与故障立即关闭条件保持原样。顶层在原许可上额外要求 `position_ready`：角度指令等于目标，连续等待 200 ms，并且当前火焰有效。

这表示软件指令已经稳定，不能证明 MG90S 机械部分确实到位。画面偏心时，虽然舵机可以转到映射角度，水泵仍受原画面中心锁定条件限制并保持关闭。本轮仅解决用户提出的固定相机舵机持续转动问题，没有将计算角度相等自动当成新的物理瞄准锁定。后续装喷嘴后再标定并讨论偏心目标的喷水许可。

水泵高/低有效参数保持可用，独立舵机自检模式继续强制水泵关闭。
