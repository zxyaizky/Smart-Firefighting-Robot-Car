# 双目基线改为 45 mm 与 SC500CS 手册核对

本轮按用户提供的两摄像头中心距 4.5 cm，将 B 板实际测距及稳定显示的 FB_CONSTANT 从 7143 同步改为 10045。双目模块保持启用，尚未接入 US-100。

## SC500CS 手册与当前配置

来源：用户提供的 `SC500CS_数据手册_V1.8.pdf`，Preliminary V1.8，2021-09-26，43 页。已阅读并渲染核对第 2、15、29、30 页。

- 第 2 页“关键指标”：像素尺寸 1.12 μm × 1.12 μm。
- 第 15 页，表 1-7“输出格式和帧率”：HD 模式 1280×720、60 fps，H/V binning 均为 2，Image Mode 为 Binning and Crop。
- 第 29 页，图 2-3“像素阵列图”：有效阵列 2592×1944，像元尺寸再次标注为 1.12 μm。
- 第 30 页，表 2-8“输出窗口寄存器”：3208/3209 为输出宽度，320a/320b 为输出高度，3210/3211、3212/3213 为输出窗口起点。

A、B 顶层均实际实例化 `uicfgcs500_720p`，其初始化表是 `uics500reg_720p60`。两份表均设置：

```text
3208/3209 = 0x0500 = 1280
320a/320b = 0x02d0 = 720
3215 = 0x31
3220 = 0x01
```

初始化表对后两项标注 VBIN+HSUB。结合手册 HD 模式，现有的 2 倍水平像元采样间距估计有依据。此检查没有修改摄像头寄存器、裁剪窗口或 A 板源文件。

## 参数推导及限制

用户已确认镜头标称焦距为 4 mm，结合新的 45 mm 基线计算：

```text
原始像元间距 = 1.12 μm = 0.00112 mm
HD 输出水平采样间距 = 2 × 0.00112 = 0.00224 mm
160 宽测距图由 1280 宽图按 8 倍采样获得
测距坐标采样间距 = 8 × 0.00224 = 0.01792 mm
f_match_pixels = 4 / 0.01792 = 223.2142857
FB_CONSTANT ≈ 223.2142857 × 45 = 10044.642857 → 10045
distance_mm = floor(FB_CONSTANT / disparity)
```

按原已取整常数直接缩放也得到同一个结果：7143 × 45 / 32 = 10044.84375，四舍五入为 10045。

手册的 1/5 英寸是光学尺寸规格，不能据此确定实际安装镜头的焦距。手册也不能替代双目内外参标定。用户已确认安装镜头的标称焦距为 4 mm，因此采用 10045；它是按名义焦距和新基线计算的光学估计，尚未经过双目标定或实测距离校准。

只改了距离比例，视差搜索、匹配门槛及显示稳定算法未改。当前搜索仍为 D=1…31，在此常数下换算范围约为 324…10045 mm；这是算法换算范围，不是已经验证的实际可用测距范围。

## 验证

复用现有 testbench，在独立目录 `simulation/stereo_baseline45` 使用新常数运行，保留历史 testbench 和原验证记录。

稳定显示的旧测试有七处写死的原基线距离值，例如 D=31 时 230 mm、D=19 时 375 mm。独立测试副本将这些期望写成 `FB / D`；没有因此修改实际显示算法。

三项测试均 PASS：

- `tb_stereo_depth_lut`：64 个视差输入，参数、取整、饱和和非法值。
- `tb_stereo_gradient_match`：63 组场景、1,173,753 次检查，保留原匹配预期，距离换算使用 10045。
- `tb_stereo_range_stability`：110 次结果、1451 次检查，稳定视差和距离换算一致。

当前顶层和对应测距/显示模块的 Verilog-2005 语法编译为 0 errors / 0 warnings。此项不是包含全部厂商 IP 的板级完整展开，也没有验证新的布局布线时序。
