## 开关和优先级

E11低电平持续20 ms启用自动。E11高电平经输入同步后停车、关泵、取消自动路线；机械臂若正在动作，会张夹并回初始位。B4只切换视频来源，不启动抓取。

优先级：**绿色完整任务 ＞ 人员近距离停车 ＞ 黄色火焰喷水 ＞ 常规前进**。绿色任务从接近到离开路线均优先。没有这些任务、机械臂未占用时，开启E11就前进；近距离未分类物体不再触发普通避障。

|S饱和度|100～255|55～255|

使用画框前的原始1280×720画面，全画面检测，不依赖运动/帧差结果；多数滤波、开运算和同行连续4像素筛选保留，每帧至少300个采样点。框在帧结束时提交，3像素死区，四分之一平滑。

黄绿存在标志及各自坐标独立，主显示框选择不影响动作、语音或Linux MMIO。Linux颜色标记只剩黄绿，原红色寄存器槽保留地址但始终无效；人员元数据和原近似前视匹配仍保留，不改Linux程序或寄存器布局。云图只着色，视频保留识别框。

喷水采用独立严格黄色标志：一个完整阴性帧、视频故障或5秒没有完整结果即撤销；重新出现需重新连续10帧确认。显示/语音可保留5帧，不会因此延长喷水。

## 绿色接近、抓取和离开

绿色确认且E11开启后：

|有效且600 ms内更新的距离|动作|
|---|---|
|≥200 mm|前进接近|
|98～199 mm|停车；机械臂处于初始位时启动抓取|
|＜98 mm|后退，进入抓取范围|
|无效或超过600 ms无更新|停车等待|

未开始抓取时，绿色丢失或结果超时取消接近；机械臂已接管后，目标丢失不会打断抓取。

|关节|初始角度|手动范围|FPGA球位|
|---|---|---|---|
|J0|135°|0～270°|E12|
|J1|90°|0～180°|E16|
|J2|0°|0～180°|E17|
|J3|180°|0～180°|F13|
|J4|90°|固定90°|F14|
|J5夹爪|0°|0～180°|F18|

动作：J1到15°、J2到5° → J3按锁存距离标定表定位 → PWM姿态命令到位后等待2秒 → J5夹紧到180°。随后严格执行：**J1到75° → J0到45° → J3到175° → J2到45° → J5张开到0° → 全部回初始位**。搬运中夹爪保持180°；普通关节每100 ms调整1°，夹爪每100 ms调整5°；PWM周期20 ms。到位指PWM命令生效，没有位置反馈。

等机械臂松夹、回位并释放控制权后：**后退到有效新鲜距离≥550 mm → 右转3150 ms → 直行5秒 → 左转3150 ms → 常规前进**。后退阶段无效/过期测距停车；后续定时段不受距离、识别丢失或人员影响，E11关闭仍取消。转向角度依赖实车标定。

同一持续绿色只抓一次，任务完成后需收到明确的无绿色完整结果，再出现才重新允许；视频故障或单纯超时不能重新允许抓取。

## 黄色火焰瞄准和喷水

需要E11开启、严格黄色确认、最近一次有效距离≤450 mm，并且没有绿色任务、机械臂占用或近距离人员停车。

动作：停车 → 按黄色独立区域中心瞄准 → 最后角度命令稳定等待**2秒** → 再取得**3次**有效目标确认 → 最多喷水**10秒**。舵机初始90°、范围10°～170°，每100 ms最多调整1°；目标角度改变重新等待。判断的是PWM命令，没有舵机反馈。

后续无效/超时测距不撤销最近有效距离许可；新的有效距离＞450 mm撤销。一个阴性帧、视频故障/结果超时、绿色接管、近距离人员或关闭E11也会结束当前喷水，不暂停后续喷。

同一持续黄色火焰仅喷一次。喷完而黄色与距离许可仍满足时继续停车；必须连续3秒没有严格黄色火焰目标才重新允许喷水。单独切换E11或把目标移远不能重新触发。

水泵`pump_ctrl_out`：**A5 / GPIOA_32 / J1第37脚，高有效**。瞄准舵机`servo_pwm_out`：**U1 / GPIOA_3 / J1第4脚**。GPIO连接驱动信号，水泵通过驱动及外部电源供电；共地。

## 人员停车

A/NPU识别经原以太网进入B板。人员存在且有效、新鲜距离≤350 mm时停车并禁止喷水；距离＞350 mm或测距无效/超过600 ms时，不仅凭人员标志停车。绿色任务优先。

人员结果5秒无新结果ID或收到损坏帧即失效；重复ID不续期。人员语音不受距离/E11限制。

## 手动按键、串口和其他显示

A9选择关节，B9每次按下调整5°，到边界后反向；自动抓取期间屏蔽手动，结束后先松开两个按键才能再操作。手动偏离初始位需恢复初始位才能自动抓取。

小车U2 TX/V2 RX预留，9600、8N1，每50 ms重发当前动作：

|动作|字节|
|---|---|
|停车|AA 00 AA|
|前进|AA 01 AB|
|后退|AA 02 A8|
|左转|AA 03 A9|
|右转|AA 04 AE|

实际速度由STM32决定，本次没有修改STM32。

语音P6 / GPIOA_11 / J1第14脚 → 模块RX，9600、8N1、3.3 V信号，并共地：

|识别|发送字节|语音|
|---|---|---|
|黄色火焰|**AA 55 01 55 AA**|检测到火焰，请小心|
|绿色|AA 55 03 55 AA|发现物资，准备收集|
|人员|AA 55 04 55 AA|检测到人员，请注意安全|

不受E11/距离限制，每类出现一次，连续消失2秒后重新允许。同时出现按黄色火焰、绿色、人员顺序排队。**不再发送02障碍物提示**；语音模块01音频需已配置。

超声波Trig=T3、Echo=T2，每200 ms测量，20 μs触发，100 ms响应超时。血氧SCL=C18、SDA=D15，自动采集显示，不参与运动/喷水；INT未使用。A4低电平开自动曝光；C7切换原图、灰度、中值、Sobel、颜色量化、运动和帧差，默认原图；原图支路加入单点/相邻双点绿色异常修复，3×3灰度中值、Sobel＋NMS和六级卡通已恢复接线；D5低有效复位。

本板J1第11脚5V、第29脚3.3V、第12/30脚GND；第28/40脚是GPIO。引脚约束在`constraints/rescue_io.adc`。
