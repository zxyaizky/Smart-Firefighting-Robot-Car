# 火焰识别后转到目标再喷水

2026-10-07。用户已验证 SW2 手动测试可以驱动水泵，并要求恢复自动喷水，明确选择“先不依赖测距，识别到火焰并转到目标后喷水”。本次仍修改 B 测距板，A/NPU 板保持不变。

## 当前默认行为

1. 无有效火焰时水泵关闭。
2. A/NPU 板的新识别结果经原 Ethernet 链路送到 B 板。B 板仍由原 `fire_control_bridge` 解析坐标与结果身份，不新建识别算法。
3. 舵机沿用固定摄像头位置模式：根据火焰 X 计算有限目标角度，每 100 ms 最多走 1°。默认 X=40/80/120 对应 80°/90°/100°，到达后停止。方向可通过 `FIRE_SERVO_REVERSE` 修改。
4. 角度指令达到目标后等待完整 200 ms。等待期间收到会改变滤波后目标角度的新结果，则重新等待。这个判断没有物理编码器反馈，不能证明舵机或喷嘴机械上已经到位。
5. 等待结束后，再连续接收 3 次仍满足位置就绪条件的独立有效火焰检测，才开启水泵。时钟周期、重复的 UDP 检测身份和一直保持的一份旧结果不能替代这 3 次新检测。
6. 后续火焰稳定在同一目标时持续喷水。目标角度变化需要重新转动时先关闭水泵，重新到达、等待并完成 3 次有效检测后再次开启。
7. 火焰有效信号撤销、无火焰/非法框的完整检测到达、原链路错误、外部复位或控制时钟域复位，立即撤销喷水许可。

摄像头固定，所以左右侧目标无需在舵机转动后回到图像中心。原增量瞄准控制器的“画面中心锁定”不再限制位置模式的喷水。若火焰目标本来就对应当前舵机角度，也会在等待和检测确认后喷水，不需要人为先转开再转回来。

`FIRE_RESULT_TIMEOUT_MS=5000` 保持原值。正常接收到无火焰结果时立即关泵；如果网线或识别结果停止更新且没有链路错误指示，则最多在最后一次独立检测之后 5 秒超时关泵。重复旧身份无法刷新这个超时。

## 模式参数

均位于 `user_source/hdl_source/design_top_wrapper.v`，修改后须重新生成并烧录：

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `PUMP_MANUAL_TEST_MODE` | 0 | 自动喷水；设为 1 可恢复已验证的 SW2 手动驱动测试 |
| `FIRE_SERVO_POSITION_MODE` | 1 | 固定摄像头位置控制；0 保留原增量追踪及中心锁定喷水条件 |
| `FIRE_PUMP_REQUIRE_DISTANCE` | 0 | 位置模式喷水暂不依赖双目距离；设为 1 要求原桥认证的 `S_fire_distance_valid` |
| `FIRE_PUMP_STABLE_SAMPLES` | 3 | 角度就绪后要求的独立有效检测次数 |
| `FIRE_SERVO_SETTLE_MS` | 200 | 最终角度指令后的稳定等待时间 |
| `FIRE_PUMP_ACTIVE_HIGH` | 1 | 高电平驱动 MOS 启动水泵 |
| `SERVO_TEST_MODE` | 0 | 独立舵机自检关闭；该自检设为 1 时仍优先强制关泵 |

关闭距离许可只改变位置模式水泵条件，双目匹配、测距、绿色框及 HDMI 距离显示仍正常运行。原增量模式的测距许可条件没有改动。

自动模式完全忽略 SW2，SW2 不是自动模式的停止开关。按板上复位可强制关闭水泵，或切断外部水泵供电。SW2 输入 B4 及其约束保留，便于以后恢复手动测试。

## 接线和下板

- 舵机信号继续使用 B 板 J1 第 4 脚，`servo_pwm_out`，FPGA U1。
- MOS 的 IN/SIG 继续使用 B 板 J1 第 5 脚，`pump_ctrl_out`，FPGA T4。
- 舵机、MOS 控制输入与 FPGA 共地；水泵和舵机使用各自合适的外部供电。水泵电流经过外部电源/MOS 回路。

## 接口推导与实现

新增独立模块 `fire_position_pump.v`：

| 接口 | 位宽 | 来源或意义 |
|---|---:|---|
| `clk` | 1 | B 的 `S_hdmi_pixel_clk`，75 MHz |
| `rst` | 1 | 原 `S_fire_ctrl_rst`，同步高有效，输出也组合关断 |
| `fire_sample_i` | 1 | 原桥 `S_fire_ctrl_sample`，每个独立识别身份计一次 |
| `fire_valid_i` | 1 | 原桥 `S_fire_ctrl_valid` |
| `position_ready_i` | 1 | 原位置控制器 `S_fire_position_ready`，合法坐标、目标角度达到及稳定等待完成 |
| `distance_allowed_i` | 1 | 当前固定为许可；参数打开时使用原桥认证的距离有效状态 |
| `pump_enable_o` | 1 | 逻辑启动许可，顶层按 MOS 有效电平输出 |

参数 `STABLE_SAMPLES=3`。只增加一个饱和检测计数器，使用组合下一状态与同步寄存器两个逻辑块；输入都来自同一时钟域，不增加跨时钟域连接。位置控制器、PWM、原瞄准控制器和原桥源文件均未修改。

新模块为 Verilog-2005，检查了端口/位宽、完整默认赋值、复位覆盖、单一驱动及无锁存器。无 AXI 接口。完整代码在 `td_project/import/fire_position_pump.v`。
